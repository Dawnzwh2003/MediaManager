## 工具限制和剩余检查

本次内置浏览器入口仍返回 `The browser access host is unavailable`。完成桌面测试并关闭测试应用后，使用独立 Chrome profile 直接打开 `http://127.0.0.1:1420/`，避免使用用户现有窗口或登录状态；工具已列出新建的 `Media Manager - Google Chrome` 窗口，但在读取该窗口/URL 时，自动审批检查再次终止 Computer Use，原因仍为无法可靠识别当前浏览器 URL。之后没有继续 UI 操作或改用其他接口绕过限制。

因此**真实浏览器页面是否显示 `desktop_required` 仍未验收**。本次拒绝仅影响浏览器专项，不抹去已经完成的原生桌面 IPC、busy、重试恢复、重启和重载结果。独立 Chrome 测试窗口在终止时保留，用户可自行关闭；本轮 Vite 服务器已停止。

其他执行说明：Windows 执行策略拒绝 `.ps1` 脚本启动后，改为在现有 PowerShell 命令中直接执行相同检查，没有修改执行策略；独立 Vite 服务器在沙箱内绑定端口返回 EACCES 后，经批准在沙箱外启动成功。Tauri/Vite 提示 wildcard 端口占用，但实际成功绑定 127.0.0.1:1420。一次无截图的按钮操作缺少几何信息，重新获取测试窗口截图后完成重试；临时只读检查脚本的 SQLite null-prototype 比较问题也已修正并重新通过，均不是应用测试失败。
